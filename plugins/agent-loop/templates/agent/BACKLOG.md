# Backlog

Tasks per milestone, in execution order. The planner writes them; the orchestrator works them top to bottom.

- `[ ]` open, `[~]` claimed (with `base: <sha>`), `[x]` done (one line, with the closing sha), `[!]` stuck (with the reason).
- Each milestone section may end with a `### Deferred hardening` subsection: parked follow-up notes, not tasks. It always stays last.
